# Shut the Box Solver
A Python implementation of differents fractales.


# Usage
Everything you want to manipulate is either in app.py or color.py 
Generate fractal: 
```bash
python -m fractales.app
```
You can either call CPU() or GPU(), also modify the values of different fractals (mandelbrot, julia....)
You can modify the color palette by changing the color argument in the function mandelbrot()
All the color palettes are in the palettes.py

tests: 
```bash
python -m pytest
```
